How American odds work

Positive odds (like +150) show profit on a $100 bet. Implied probability = 100 / (odds + 100).

Negative odds (like -150) show what you'd need to bet to win $100. Implied probability = |odds| / (|odds| + 100).

Bigger negative number = bigger favorite. Bigger positive number = bigger underdog. You won't have time to do this math — the game is here to build the gut feel instead.
